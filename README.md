# 电眼美女 · 大宋上元篇 V5.1

## 在线玩

**[点击进入游戏 →](https://mumumuqingnuan.github.io/shangyuan-heartbeat/)**

游戏网址：<https://mumumuqingnuan.github.io/shangyuan-heartbeat/>

无需登录，手机、平板和电脑浏览器均可打开；支持横屏和竖屏。将游戏网址添加到桌面或主屏幕后，下次点击图标就能进入。

150 秒宋风灯市小游戏：三处街景、三套衣装、二十三种归宿。点人放电、右侧连点争艳、点地面移动；音乐在开始游戏后启用，可随时关闭。

## 添加到桌面 / 主屏幕

先用浏览器打开上面的**游戏网址**，再按设备操作：

- **iPhone / iPad**：用 Safari 打开游戏，点「分享」→「添加到主屏幕」→「添加」。新版本可选择「作为网页 App 打开」。
- **安卓手机 / 平板**：用 Chrome 打开游戏，点右上角「⋮」→「安装并创建快捷方式」→「创建快捷方式」→「添加」。部分版本显示「添加到主屏幕」，按提示添加即可。
- **电脑 Chrome**：打开游戏，点右上角「⋮」→「投放、保存和分享」→「创建快捷方式…」，名称可填「大宋上元篇」，再点「创建」。

添加后，点桌面或主屏幕上的图标就能进入游戏。快捷方式仍需联网使用；当前版本未提供离线模式。不同系统和浏览器版本的菜单名称可能略有不同。

官方操作说明：[iPhone](https://support.apple.com/zh-cn/guide/iphone/iphea86e5236/ios) · [iPad](https://support.apple.com/zh-hans/guide/ipad/ipad8f1f7a29/ipados) · [安卓 Chrome](https://support.google.com/chrome/answer/15085120?co=GENIE.Platform%3DAndroid&hl=zh-Hans) · [电脑 Chrome](https://support.google.com/chrome/answer/15085120?co=GENIE.Platform%3DDesktop&hl=zh-Hans)

## 静态部署

本目录是可直接发布的完整静态站点，无需构建或服务端。将目录内所有文件（包括 `.nojekyll`）上传至 GitHub 仓库根目录，在 **Settings → Pages** 选择 **Deploy from a branch**、目标分支和 **/(root)**。

本地预览：在本目录运行 `python3 -m http.server 8080`，再访问 `http://localhost:8080/`。请通过 HTTP 服务打开，以便浏览器加载 JavaScript 模块。

## 收藏

缘分簿使用 `localStorage`，仅保存在当前浏览器的当前站点来源中，不会跨设备同步。原内部站点或其他域名下的收藏不会自动转入本网页；清除站点数据也会清除收藏。
